🌌 NovaSpace — Modern Animated Landing Page

NovaSpace is a modern and futuristic landing page built using HTML and CSS. The project focuses on creating an attractive user interface with animated backgrounds, glowing effects, glassmorphism, gradients, and smooth hover animations.

✨ Features
🎨 Modern futuristic UI design
🌌 Animated neon background effects
🔵 Radial gradient glowing effects
▦ Subtle CSS grid background
💎 Glassmorphism card design
🪐 Animated 3D-style planet
✨ Gradient typography
🖱️ Smooth hover effects
📱 Responsive design for mobile and desktop
⚡ Built with pure HTML & CSS
🛠️ Technologies Used
HTML5
CSS3
CSS Gradients
CSS Animations
CSS Flexbox
CSS Grid
Responsive Media Queries
📂 Project Structure
NovaSpace/
│
├── index.html
└── style.css
🚀 How to Run
Clone or download this repository.
Open the project folder.
Open index.html in your browser.
Enjoy the animated NovaSpace landing page! 🚀
🎯 Purpose

This project was created to practice and demonstrate modern HTML & CSS UI design techniques, especially animated backgrounds, gradients, glassmorphism, responsive layouts, and CSS animations.
